How to use Inspection Data Hub

REFERENCE GUIDE

This application helps you consult past EST / Plant observations while preparing invoices and deciding what to review. It is a historical reference, not an official verification of today's shipment.

1 · Search Items for a POEach successful Meat or Dairy Item lookup automatically adds it to the current PO worklog. Repeated lookups are not duplicated.
2 · Save the POEnter the Purchase Order number and save. The current worklog clears, and the saved invoice remains available below.
3 · Inspect cases physicallyReopen the saved PO after inspecting pallets. Editing an EST reference alone does not count as a verification.
4 · Confirm or change ESTConfirm matching ESTs or enter one or more different ESTs actually observed on the cases. Only these actions update physical verification statistics.

Understanding the product card

Latest confirmed EST / Plant

The establishment value or values recorded at the most recent verification date. It does not claim every case on the pallet has that number.

Last 10 verified weeks

Frequency across the last 10 calendar weeks that contain actual observations, not simply the last 10 calendar weeks and not the last 10 searches.

All-time history

Frequency across every week with recorded observations for the Item. Old data remains in the history.

All observed variants

Every EST / Plant value confirmed for the Item, including older or uncommon values. More than one can be observed in a week.

Days without verification

Elapsed days since the last physically confirmed observation. Searching the Item does not reset this timer.

Frequency percentage

Weeks where an EST was observed ÷ total weeks with observations. If two ESTs appear in the same week, both count once, so percentages can add up to more than 100%.

Suggested review priorities

Default guide thresholds · not inspection policy
HIGH PRIORITYNormal products

Never verified, more than 60 days since the last physical verification, or multiple distinct ESTs observed within the last 10 verified weeks.

REVIEW ADVISEDNormal products

15–60 days without physical verification, provided no recent EST variation is recorded.

LOWER PRIORITYNormal products

Verified within the last 14 days, with one EST in the recent verified history.

A change means different EST values have been physically recorded within the last 10 verified weeks, not an automatically detected manufacturing change. This overrides even Highly Stable brand classifications and shows HIGH PRIORITY in red. Priority is guidance, not a substitute for required inspection procedures.

Highly stable products

MANUALLY CLASSIFIED

Use Mark highly stable only for an Item with a well-established history of the same EST. This is a manual label, not an automatic claim that the establishment cannot change. It applies to an individual Item, not every product from the same brand.

LOWER PRIORITYLess than 6 months

Since the last physical verification.

REVIEW ADVISED6 to under 12 months

Time to consider checking this Item again.

HIGH PRIORITY12 months or more

A new physical verification is strongly recommended. Any EST variation within the last 10 verified weeks triggers HIGH PRIORITY sooner.

A highly stable label does not override the normal requirement to verify products when necessary. If a different EST is observed, review whether the label is still appropriate; the application does not independently determine that a manufacturer changed plants.

Example: how weekly frequency works

Week 1EST 471 confirmed
Week 2EST 471 confirmed three times → counted once
Week 3No physical check → no observation
Week 4EST 471 and 81B confirmed → both counted once

Result: 471 appears in 3 of 3 verified weeks (100%) and 81B appears in 1 of 3 (33%). Week 3 does not count as an EST confirmation. These percentages describe only the observations that were entered.

Brands · Profiles and stability inheritance

BRAND RULES

Brands are internal reference profiles for manufacturer descriptions, establishment numbers, notes and product types. Only enter plant facts that have been verified from reliable records; a brand's EST list is not an official guarantee about today's cases.

Single fixed EST

One known EST for the applicable Items. A brand can optionally assign Highly Stable to matching products when that fixed number is entered.

Fixed EST by product type

Assign separate EST references to Beef / Pork, Poultry, Dairy or Other. Only matching product types with a configured number inherit Highly Stable.

Variable / Item-specific

Use each product's own verification history and standard review intervals. Brand-level stability inheritance is not applied.

Item-level exceptions

An administrator can override inherited stability for an individual Item. This takes precedence over the brand's general rule.

A brand may have more than one EST yet remain historically stable by product type. Stability is a review scheduling aid, not proof that a plant cannot change. If an unexpected number appears, record what you actually saw and review the reference rule.

Verification History · Fast workflow

1 · Search or queue an ItemLook up products normally or scan them into the quick queue. The queue shows each Item once even when searched repeatedly.
2 · Check the physical casesUse the checkbox only if you personally inspected that product. Searches alone do not count as physical verifications.
3 · Confirm matching ESTsSelect checked Items with one latest confirmed EST and press Confirm selected. You must confirm that the physically seen EST matches.
4 · Record a different or mixed ESTUse Different EST / mixed to choose several observed values or enter a new one. The date defaults to today.

The verification records table shows confirmed observations. The collapsible Search history is only a consultation log; it does not measure physical inspections. The queue is a temporary working list in this preview.

Database Sync · Preview status

Database connectivity and permanent storage are not implemented in this web design preview. Do not enter live credentials. Sample records, manual observations and brand profile changes are temporary and may reset when the page reloads.

Common questions

Does looking up an Item confirm its EST?

No. Only using Verify EST after physically checking the cases adds an observation.

Can a product have two or three EST values?

Yes. The card shows all confirmed variants. You can select multiple values in the verification popup if you physically observed them.

What if I only check a few cases from a large pallet?

Record the ESTs you actually observed. The app does not assume that every case or every unexamined product matches your sample.

Can I correct an incorrectly entered observation?

Yes. An administrator can open View / correct records. In this web prototype, edits are temporary.

Is a highly stable product guaranteed not to change?

No. The classification only adjusts the suggested review interval. Physical checks remain important.

Does the web preview save records permanently?

No. This is a design prototype with sample data. Observations and stability labels reset when you reload the page.
