Security layers added

  • Cloudflare backend: checks protected requests before they reach Supabase.
  • Database protection: Supabase also checks access to data and private files.
  • User permissions: each account keeps its own access; administrator tools stay restricted.
  • Server-side tokens: sign-in tokens stay on the server, outside browser storage.
  • Protected sessions: secure cookies, session checks and automatic token renewal.
  • Session control: expiry, sign-out and immediate access revocation.
  • Request checks: protection against forged requests, with limits on sign-in attempts.
  • Old access closed: legacy sessions retired and direct data access restricted.
  • Development records: changes, tests and rollback procedures documented.

Prepared & still in progress

  • Authenticator codes: two-step verification setup is partly implemented; account activation and testing remain.
  • Email codes: the verification flow is prepared; email delivery setup and testing remain.
  • Account recovery: the recovery procedure still needs completion and testing.
