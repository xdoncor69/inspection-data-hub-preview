# Inspection Data Hub — Public Preview

This repository contains only a standalone HTML/CSS/JavaScript demonstration of Inspection Data Hub. The main project remains private.

- Demo entry point: [`index.html`](./index.html)
- Intended GitHub Pages URL: https://xdoncor69.github.io/inspection-data-hub-preview/
- All demo PO records and verification events are stored in the browser's `localStorage` only, not synced between devices.
- No secure backend or real authentication is provided. Do not enter real customer information, confidential records or passwords.

## Publish with GitHub Pages

In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, **main**, **/(root)**, then **Save**. Wait for the deployment to complete.

Future updates should copy the private project's `preview/index.html` into this public repository's `index.html`.
